# Static Assets

This directory contains static assets that are served directly by Vite.

## NOVA Classification Image

Place your NOVA classification image here as `nova-classification.png` to display it on the dashboard.

The image should show the 4 NOVA groups:
1. **Group 1** - Unprocessed or minimally processed foods (emerald/green)
2. **Group 2** - Processed culinary ingredients (blue)
3. **Group 3** - Processed foods (amber/yellow)
4. **Group 4** - Ultra-processed foods (red)

The image will be displayed in the Tips section of the upload page.
